# Волна для Android

На телефоне можно запустить волну, найти конкретную песню или добавить свои аудиофайлы. В «Источниках» плеер принимает ссылки magnet и файлы `.torrent`. Он скачивает нужный аудиофайл и проверяет его перед воспроизведением.

Плеер готовит до четырёх следующих треков. Если нажать «Дальше», пока очередной трек качается, загрузка продолжится с повышенным приоритетом. Каталог, история, оценки и кеш хранятся на телефоне. Пауза и переключение работают в шторке, на экране блокировки и через медиакнопки.

## Сборка из исходников

Понадобятся JDK 17 и Android SDK с платформой API 35. Следующие команды запускай из папки `android/`:

```bash
export ANDROID_HOME="$HOME/Android/Sdk" # Укажи свой путь к SDK.
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

Gradle скачает свои зависимости при первой сборке. APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Он подходит для Android 8 и новее на `arm64-v8a` или `x86_64`.

Можно открыть APK в файловом менеджере телефона или поставить его через ADB:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
